01 · 수업 현장 · 학습 도구

교사와 학생이 실제 수업과 학습 활동에서 활용할 수 있는 도구

01 · CLASSROOM TOOL

Our One-Day Trip

초등 영어의 ‘I am going to’ 표현과 사회과의 세계화 내용을 연결해, 학생이 직접 여행 계획을 세우며 학습 내용을 실제 맥락에 적용하도록 만든 웹 기반 수업 도구입니다.

Claude Artifacts를 활용해 지도 앱의 기능을 초등학생 수준에 맞게 단순화하고, 도시·장소·이동수단과 시간을 선택해 일정을 구성할 수 있도록 구현했습니다. GitHub Pages로 배포해 수업에서 사용할 수 있는 형태까지 완성했습니다.

02 · LEARNING APP

두리번수학

유아가 수학 개념을 탐색하고 경험할 수 있도록 기획한 학습 앱으로, 교육 현장에서 발견한 요구를 디지털 학습 경험으로 전환한 프로젝트입니다.

Genspark를 활용해 초기 버전을 기획부터 제작까지 구현했으며, 실제 사용자 테스트 결과를 바탕으로 기능과 사용 흐름을 개선했습니다. 교육적 아이디어를 AI 도구로 빠르게 프로토타이핑하고 검증한 경험입니다.

02 · 교육 서비스

학습자의 성장과 학습 경험을 지원하는 디지털 서비스

03 · EDUCATION SERVICE

GrowEng

초등 영어 학습자를 위한 AI 영어 읽기 평가·학습 서비스입니다. 교사가 모든 학생의 읽기 수행을 개별적으로 확인하기 어렵다는 현장 문제에서 출발했습니다.

학습자의 읽기 수준을 확인하고 결과에 맞는 학습 경험으로 이어질 수 있도록 서비스 흐름과 화면을 설계했습니다. 화면 설계, 디자인 시스템과 캐릭터 제작에도 생성형 AI를 활용해 아이디어를 빠르게 시각화하고 구체화했습니다.

04 · EDUCATION SERVICE

STUD.IO

학습자가 자신의 학습 정보를 기록하고 계획과 리포트를 이어서 확인할 수 있도록 설계된 학습 지원 서비스의 프런트엔드 개발에 참여했습니다.

React Native와 Expo를 기반으로 학습 정보 입력, 학습 계획, 리포트 등 주요 화면과 사용자 흐름을 구현했습니다. 화면 간 상태 유지와 서버 연동 과정에서 발생한 오류를 해결하며 실제 서비스의 사용성과 완성도를 높였습니다.

03 · AI · 데이터 기술

교육 문제 해결을 뒷받침하는 AI·데이터 모델링 및 구현 역량

05 · AI · DATA

ConFuse

스마트폰·스마트워치 라이프로그를 활용해 수면 상태를 예측하는 연구로, 구조화된 수치 데이터에 강한 GBDT와 개인의 행동 맥락을 해석하는 LLM을 결합했습니다.

데이터 신뢰도 점수에 따라 샘플별 LLM 활용 비중을 조절하는 context-aware fusion을 설계하고, 개인별 baseline을 반영한 LLM 학습과 GBDT ensemble을 함께 검증했습니다. 고정 50:50 결합보다 낮은 log loss를 기록했으며 ICTC 2026에 채택되었습니다.

06 · AI · DATA

한국어 유튜브 허위정보 판별 AI 서비스

한국어 유튜브 영상 1,435건의 데이터셋을 구축하고, 영상의 텍스트 정보를 바탕으로 허위정보 여부와 예측 신뢰도를 함께 제시하는 AI 서비스를 개발했습니다.

LLM의 반복 추론 결과를 집계하고 Conformal Prediction으로 불확실성을 정량화해, 근거가 부족한 경우 무리하게 단정하지 않는 신뢰도 기반 판별 구조를 설계했습니다. 데이터 구축·모델링·실험부터 일반 사용자가 이용할 수 있는 웹서비스 구현까지 End-to-End로 수행했습니다.
